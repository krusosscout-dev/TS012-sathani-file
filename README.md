# สถานีไฟล์

เว็บสำหรับรวม จัดหน้า แยก PDF และแปลงรูปภาพ ทำงานในเบราว์เซอร์ทั้งหมด ไฟล์ของผู้ใช้ไม่ถูกอัปโหลดไปที่ใด
ติดตั้งเป็นแอปได้ และใช้งานได้แม้ไม่มีอินเทอร์เน็ต (ลงทะเบียนครั้งแรกต้องต่ออินเทอร์เน็ต)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด (หน้าตา + การทำงาน) |
| `manifest.webmanifest` | ข้อมูลแอป (ชื่อ ไอคอน สี) ทำให้ติดตั้งเป็นแอปได้ |
| `sw.js` | เก็บหน้าเว็บและเครื่องมือไว้ในเครื่อง ให้เปิดได้ตอนไม่มีเน็ต |
| `icon-*.png`, `favicon.svg` | ไอคอนแอปและไอคอนบนแท็บ |
| `vercel.json` | ตั้งค่าให้ Vercel ส่ง `sw.js` ตัวล่าสุดเสมอ |
| `api/stats.js` | ตัวนับสถิติที่แสดงบนหน้าแรก |
| `api/register.js` | รับข้อมูลลงทะเบียนของครู |
| `api/admin.js` | หน้าผู้ดูแล: ดูและลบรายชื่อ |

ไม่ต้องติดตั้งหรือ build อะไรเพิ่ม เป็นเว็บแบบ static

## การบันทึกไฟล์

- คอมพิวเตอร์ (Chrome, Edge): เปิดหน้าต่าง "บันทึกเป็น…" ให้เลือกโฟลเดอร์และชื่อไฟล์
- มือถือ/แท็บเล็ต: เปิดเมนูแชร์ของเครื่อง เพื่อบันทึกลงแอปไฟล์ ส่ง LINE หรือ Google Drive
- เบราว์เซอร์อื่น: ดาวน์โหลดลงโฟลเดอร์ Downloads
- ปิดการถามได้จากช่องติ๊กที่หัวเว็บ

## สถิติผู้ใช้งาน

มี 2 แบบ ใช้ได้ฟรีทั้งคู่

1. **ตัวเลขบนหน้าแรก** (ทุกคนเห็น): ครูที่ลงทะเบียน ครั้งที่เปิดใช้งานทั้งหมด และจำนวนไฟล์ที่สร้าง
   ทำงานผ่าน `api/stats.js` และต้องเชื่อมฐานข้อมูลฟรี **Upstash for Redis** กับโปรเจกต์ก่อน
   (Vercel → โปรเจกต์ → Storage → Create Database → Upstash for Redis → Connect แล้ว Redeploy)
   ระหว่างที่ยังไม่ได้เชื่อม หน้าแรกจะซ่อนแถบตัวเลขไว้
2. **Vercel Web Analytics** (เจ้าของเห็นคนเดียว): ประเทศ อุปกรณ์ เว็บที่ส่งคนมา
   เปิดใช้: Vercel → โปรเจกต์ → Analytics → Enable แล้ว Redeploy

ทั้งสองแบบเก็บแค่ตัวเลข ไม่เก็บไฟล์หรือข้อมูลส่วนตัวของผู้ใช้

## การลงทะเบียนและหน้าผู้ดูแล

- ครูกรอกข้อมูลครั้งเดียวต่อเครื่องก่อนเข้าเครื่องมือ: ชื่อ-นามสกุล ตำแหน่ง โรงเรียน สังกัด และแลกเปลี่ยนเรียนรู้ (ไม่บังคับ) พร้อมกดยินยอมตามประกาศความเป็นส่วนตัว
- ไม่เก็บอีเมล เบอร์โทร ที่อยู่ IP หรือไฟล์ของผู้ใช้
- ถ้าฐานข้อมูลยังไม่เชื่อมหรือใช้งานไม่ได้ ระบบจะให้เข้าใช้งานได้ทันที ไม่ล็อกครูไว้
- หน้าผู้ดูแล: เปิด `/#admin` แล้วใส่รหัสผ่าน ดูรายชื่อ ค้นหา ลบรายชื่อ และดาวน์โหลดเป็นไฟล์ Excel (CSV)
- ตั้งรหัสผ่านผู้ดูแล: Vercel → โปรเจกต์ → Settings → Environment Variables → เพิ่ม `ADMIN_PASSWORD` แล้ว Redeploy
- ใส่รหัสผิด 10 ครั้ง ระบบจะล็อก 15 นาที
- แก้ข้อความประกาศความเป็นส่วนตัว: ใน `index.html` ค้นหาคำว่า `ประกาศความเป็นส่วนตัว`

## แก้ชื่อผู้พัฒนาบนหน้าแรก

ใน `index.html` ค้นหาคำว่า `พัฒนาโดย` แล้วแก้ข้อความในบรรทัดนั้น

## วิธีแก้ไขภายหลัง

แก้ `index.html` บน GitHub แล้วกด Commit changes ประมาณ 1 นาที Vercel จะอัปเดตเว็บให้อัตโนมัติ
คนที่ติดตั้งแอปไว้แล้วจะได้เวอร์ชันใหม่เมื่อเปิดแอปตอนมีอินเทอร์เน็ต
ถ้าเปลี่ยนเวอร์ชันไลบรารีใน `index.html` ให้เปลี่ยน `VERSION` และรายการ `LIBS` ใน `sw.js` ให้ตรงกันด้วย

## ไลบรารีที่ใช้ (โหลดจาก cdnjs)

- pdf-lib 1.17.1 สำหรับรวม แยก และหมุนหน้า PDF
- pdf.js 3.11.174 สำหรับแสดงภาพย่อ และแปลง PDF เป็นรูป
- JSZip 3.10.1 สำหรับรวมหลายไฟล์เป็น ZIP
